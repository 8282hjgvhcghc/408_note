# 数据结构

## 第一章 绪论

### 时间复杂度分析

**关键**：数循环次数与递归调用。

- 基本操作数量级判断：O(1)、O(logn)、O(n)、O(nlogn)、O(n²) 等
- 顺序语句叠加，循环看循环体执行次数，递归看递推关系

### 算法评价要素

- 时间复杂度：基本操作执行次数随问题规模增长的数量级
- 空间复杂度：算法运行过程中临时占用的存储空间
- 通常题目要求时间优先，空间可折中

## 第二章 线性表

### 顺序表与链表性能对比

- 增删：顺序表 O(n) / 链表 O(1)（已知结点）/ 静态链表 O(1)
- 查找：顺序表 O(1)（按下标）/ 链表 O(n) / 静态链表 O(n)
- 适用场景：顺序表适合随机访问频繁、增删少的场景；链表适合频繁插入删除

### 链表操作要点

- 明确是否有头结点、指针类型
- 画图标记结点与指针关系
- 逐步骤检验是否断链：结点无法通过指针访问
- 考虑极端情况：空表、单结点

### 静态链表

- 借助数组，用游标（下标）代替指针
- 结点插入删除只需修改游标，不需移动元素

## 第三章 栈、队列和数组

### 栈队列下标计算

- 栈：top 指向栈顶或下一个位置，入栈 top+1
- 队列：入队 rear+1；出队 front+1；循环队列需取模 n
- 循环队列：front=(front+1)%n；rear=(rear+1)%n

### 栈队列应用

- 栈：表达式求值、括号匹配、DFS、先中后序遍历
- 队列：层次遍历、BFS、缓冲区

### 中缀转后缀关键步骤

1. 遇数字 → 直接输出
2. 左括号 → 压栈
3. 右括号 → 弹出至左括号，括号不输出
4. 运算符 → 与栈顶比优先级：高则压栈，低则弹出后重新比较
5. 末尾 → 栈内剩余运算符全弹出

### 矩阵存储

- 确定类型：普通/上下三角/三对角
- 确定优先级与起始下标（默认行优先、从0开始）
- 特殊矩阵：三元组表、十字链表

## 第五章 树与二叉树

### 树转二叉树

- 原则：左孩子、右兄弟
- 森林先根遍历 ↔ 对应二叉树先序遍历
- 森林后根遍历 ↔ 对应二叉树中序遍历

### 树的结点数与高度关系

- 总结点数 n = 边数 + 1 = Σ(度为i的结点数) + 1
- 满m叉树：n = (m^h - 1)/(m - 1)；h = log_m[n(m-1)+1]
- 完全二叉树：2^(h-1) < n ≤ 2^h - 1；h = ⌈log₂(n+1)⌉

### 四种遍历

- 先序：根→左→右
- 中序：左→根→右
- 后序：左→右→根
- 层序：逐层左到右
- 关键：已知中序 + 任一遍历 ⇒ 唯一确定二叉树

### 卡特兰数

- 应用：n个元素出栈序列数、n个节点二叉树形状数、n对括号匹配数
- 公式：C_n = C(2n,n)/(n+1)

### 哈夫曼树与编码

**构造**：每次选权值最小的两结点合并，权值 = 左右孩子权值和。

**关键性质**：
- 无度为1结点
- 权值大的离根近
- WPL最小 = 所有非叶结点权值和
- 叶结点n个 ⇒ 非叶n-1个 ⇒ 总结点2n-1个
- 前缀码：每个码字都不是其他码字的前缀

**编码**：根往下，左0右1。

### 线索二叉树构造

1. 写出遍历序列
2. 逐结点判断是否有孩子
3. 无孩子则填线索指针（根据遍历序列）

### 并查集

- 原理：集合中元素代表集合
- 存储：双亲表示法（数组）
- 操作：Find（连通性）、Union（合并）
- 应用：连通性判断、判环、Kruskal算法
- 优化：路径压缩、按秩合并

### 树的顺序存储

- 双亲表示法：通过数组下标关系找父节点和孩子

## 第六章 图

### 基本概念与计算

- 连通图：任意顶点间都有路径
- 完全图：任意两顶点间都有边
- 顶点度：相邻边数
- 无向图连通：最少边 n-1，最多边 n(n-1)/2
- 有向图强连通：最少边 n，最多边 n(n-1)

### 拓扑排序模拟

1. 选入度为0顶点输出
2. 删除该顶点及相连边
3. 重复直至所有顶点处理完
- 求序列个数时用升序方式避免遗漏

### AOE网与关键路径

1. 源→汇：求各顶点最早开始时间 ve
2. 汇→源：求各顶点最迟开始时间 vl
3. 时间余量 = vl(终点) - ve(起点) - 边长
4. 余量为0的边 = 关键路径
- 或：直接观察找最长路径

### BFS与DFS

- BFS：队列维持，逐层访问相邻未访问结点
- DFS：递归深度优先，无相邻未访问结点时回退

### 最小生成树

- **Prim**：从顶点集合T出发，每次加入最近顶点。优选稠密图。
- **Kruskal**：边排序，每次加不成环最小边。优选稀疏图。

### Dijkstra单源最短路径

1. 维持集合S和dist数组
2. 从dist选最小值顶点x加入S
3. 用x更新相邻顶点dist（dist[x]+weight < dist[y]时更新）
4. 重复直至所有顶点加入S

### 图算法时间复杂度

- DFS/BFS：邻接矩阵 O(n²)，邻接表 O(n+e)
- Dijkstra：邻接矩阵 O(n²)，邻接表 O((n+e)logn)
- Prim：邻接矩阵 O(n²)，邻接表 O((n+e)logn)
- Kruskal：O(eloge)
- 拓扑排序：邻接矩阵 O(n²)，邻接表 O(n+e)

## 第七章 查找

### 二叉排序树 vs AVL vs 红黑树对比

- 二叉排序树：无平衡要求，最差树高 O(n)
- AVL：平衡因子 |因子|≤1，树高 O(logn)，旋转频繁
- 红黑树：满足四性质，树高 O(logn)，旋转较少

### 红黑树四个性质

1. 结点红或黑色
2. 根、叶为黑 → "根叶黑"
3. 无相邻红结点 → "不红红"
4. 根到叶黑结点数相同 → "黑路同"

### AVL树旋转

- 四种情况：LL（右旋）、RR（左旋）、LR（先左后右）、RL（先右后左）
- 判断依据：不平衡结点的较高孩子方向

### B树与B+树

- 阶为m：根分支数∈[2,m]；非根∈[⌈m/2⌉,m]
- B树：关键字数 = 分支数 - 1
- B+树：关键字数 = 分支数

**插入步骤**：
1. 查找合适叶结点
2. 插入并保持有序
3. 满则分裂：中间关键字上升

### 散列表冲突处理

- 线性探测：逐个探测后续位置
- 链地址法：同键值用链表连接

**ASL计算**：
- 成功：每个关键字查找次数和 ÷ 关键字数
- 失败：所有失败位置查找次数和 ÷ 表长
- 注意：线性探测访问空位算一次；链表空指针不计

### KMP算法

- 核心：根据模式串构造next数组
- 步骤：
  1. 计算next（或nextval）
  2. 利用next快速跳过失配位置
- 注意：next[0]=-1；区分next与nextval

### 折半查找

- 前提：有序顺序表
- 时间复杂度：O(logn)
- 查找判定树：必为平衡树，前n-1层为满树

### 查找方式比较

- 顺序查找：数组/链表，O(n)
- 折半查找：有序数组，O(logn)
- 分块查找：分块数组，O(log m + n/m)
- 二叉排序树：树，最差 O(n)
- 平衡二叉树：树，O(logn)
- 散列查找：哈希表，O(1) 平均

## 第八章 排序

### 各排序算法对比

- 直接插入：最差 O(n²)、平均 O(n²)、空间 O(1)、稳定
- 折半插入：最差 O(n²)、平均 O(n²)、空间 O(1)、稳定
- 希尔排序：最差 O(n²)、平均 O(nlogn)、空间 O(1)、不稳定
- 冒泡排序：最差 O(n²)、平均 O(n²)、空间 O(1)、稳定
- 快速排序：最差 O(n²)、平均 O(nlogn)、空间 O(logn)、不稳定
- 简单选择：最差 O(n²)、平均 O(n²)、空间 O(1)、不稳定
- 堆排序：最差 O(nlogn)、平均 O(nlogn)、空间 O(1)、不稳定
- 归并排序：最差 O(nlogn)、平均 O(nlogn)、空间 O(n)、稳定

### 排序过程模拟关键点

- 直接/折半插入：第i趟后前 i+1 个元素有序
- 希尔排序：第i趟间隔 d_i 的子序列有序
- 冒泡：第i趟最小（大）元素进入最终位置
- 快速：第i趟若干枢值进入最终位置
- 选择类（简单选择、堆排）：第i趟最小（大）元素进入最终位置

### 判断排序方法

1. 与升序对比，找已在最终位置元素
2. 检查是否符合各排序特征
3. 观察前几个元素有序情况 → 插入类
4. 看是否有特定步长 → 希尔排序

### 元素最终位置性质

- 能确保在最终位置：选择类（简单选择、堆排）、交换类（冒泡、快速）
- 不能确保：插入类（直接插入、折半插入、希尔）、归并

### 外部排序

- 置换选择排序：利用内存工作区生成初始归并段
- 最佳归并树：根据初始段数确定虚段数，满足m叉树结构
- 败者树：树形选择排序，叶结点存当前元素，根结点指向最小值

## 解题框架与常考陷阱

### 选择题

1. 明确核心概念与适用条件
2. 对比关键特征差异
3. 排除法筛选
4. 注意隐含条件

**常考陷阱**：
- 树的节点数与高度关系、满树与完全树
- 链表断链判断
- 栈队列下标计算
- 排序稳定性
- 图连通性
- 查找成功失败平均长度

### 计算题与模拟题

- 链表操作：明确结构 → 画图 → 逐步检验断链
- 栈队列下标：明确定义 → 举例验证 → 注意循环
- 树遍历转化：明确规则 → 按步骤操作 → 验证结果
- 哈夫曼树：反复选最小权合并 → 画树 → 计算WPL或编码
- 图算法：明确步骤 → 逐步模拟 → 记录中间结果
- 排序模拟：明确算法 → 逐趟操作 → 标记最终位置
- 树的旋转：检测不平衡 → 判断类型 → 执行旋转 → 检查祖先
- B树插入：查找位置 → 插入保序 → 判断分裂 → 继续处理
- KMP：推导next → 模拟匹配过程

### 综合大题

- 数据结构设计：分析要求 → 选择结构 → 设计方案 → 模拟验证 → 分析复杂度
- 算法分析优化：理解逻辑 → 分析复杂度 → 找瓶颈 → 给出改进
- 树图复合问题：理解结构 → 提取关键信息 → 应用算法 → 画图说明
