# 408 知识点笔记库

408 考研笔记仓库。所有笔记按科目组织，并按来源分两个目录存放：

## 目录结构

- `Notion笔记/`：已同步到 Notion 的正式笔记。每篇笔记同时存在于本地文件、Notion、本仓库，三方一致
- `本地笔记/`：仅保存在本地的提纲与笔记，未上传 Notion
- `索引.md`：全部笔记的目录索引（含来源标注）

## 同步说明

- 归档流程：答疑整理出笔记后，先写入 `Notion笔记\<科目>.md`，再上传到 Notion，最后推送本仓库
- 用户明确要求"只存本地、不上 Notion"的笔记，写入 `本地笔记\<科目>.md` 后推送本仓库
- 推送需要本机代理软件开启（git 已配置代理 127.0.0.1:7890）
